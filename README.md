# Common Thread Student Collective

Website for a student-run nonprofit that helps kids in foster care and nursing-home residents.

The whole site is one file, `index.html`.

## Before you share it
- Replace the placeholder name, school, email, numbers and milestones with your real ones.
- Remove the "Preview" banner at the top (`<div class="notice">`).
- Paste your donation page link into `const DONATE_URL = "";` near the bottom of `index.html`.

## Publish with GitHub Pages
Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / root → Save.
