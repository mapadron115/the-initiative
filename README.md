# The Smile Exchange

Website for The Smile Exchange, a student-run company (Junior Achievement of Greater Miami Company Program, MLEC Finance Class of 2027) that brings companionship, care packages and handwritten letters to nursing-home residents.

Live site: https://mapadron115.github.io/the-initiative/

## Files
- `index.html` – the whole site
- Photos are built into index.html, so it is the only file needed

## To turn on online donations
Open `index.html`, find `const DONATE_URL = "";` near the bottom, and paste your donation page link between the quotes (Zeffy, Givebutter, PayPal, etc.).
